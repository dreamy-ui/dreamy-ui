## Installation

```bash
bunx dreamy add radio
```

## Usage

Radio behavior and keyboard navigation are powered by [UI SDK Radio](https://ui-sdk.dev/docs/components/radio). Use `checked`, `defaultChecked`, and `onCheckedChange` on standalone `Radio` components, or `value`, `defaultValue`, `onValueChange`, and `disabled` on `RadioGroup`.

Radio buttons allow users to select one option from a set of mutually exclusive choices. Perfect for single-selection scenarios in forms.

<Wrapper>
	<Radio value="default" defaultChecked>
		<>Default</>
	</Radio>
</Wrapper>

```tsx
<Radio value="default" defaultChecked>
	Default
</Radio>
```

### Radio Group

`RadioGroup` allows easily composing multiple radios.

Use `defaultValue`, `value`, and `onValueChange` in `<RadioGroup />` to control the selected radio.

<Wrapper>
	<RadioGroup defaultValue="1">
		<Radio value="1">First</Radio>
		<Radio value="2">Second</Radio>
	</RadioGroup>
</Wrapper>

```tsx
<RadioGroup defaultValue="1">
	<Radio value="1">First</Radio>
	<Radio value="2">Second</Radio>
</RadioGroup>
```

### Disabled

Pass `disabled` to `RadioGroup` to disable all radios in the group, or to an individual `Radio`.

<Wrapper>
	<RadioGroup defaultValue="1" disabled>
		<Radio value="1">First</Radio>
		<Radio value="2">Second</Radio>
	</RadioGroup>
</Wrapper>

```tsx
<RadioGroup defaultValue="1" disabled>
	<Radio value="1">First</Radio>
	<Radio value="2">Second</Radio>
</RadioGroup>
```

### Controlled Radio

You can control the Radio state by using `value` and `onValueChange` in `<RadioGroup />`.

<Wrapper>
	<ControlledRadios />
</Wrapper>

```tsx
export function ControlledRadios() {
    const [value, setValue] = useState<string | null>("rr");

    return (
        <RadioGroup
            value={value}
            onValueChange={(next) => setValue(next)}
        >
            <Radio value="rr">React Router</Radio>
            <Radio value="next">Next.js</Radio>
            <Radio value="vue">Vue.js</Radio>
        </RadioGroup>
    );
}
```
