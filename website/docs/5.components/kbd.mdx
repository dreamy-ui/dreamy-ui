## Installation

```bash
pnpm dreamy add kbd
```

## Usage

You can press action key and `i` to toggle the color mode.

<Wrapper>
	<Kbd>^i</Kbd>
</Wrapper>

```tsx
<Kbd>^i</Kbd>
```

### Variants

The `Kbd` component comes in two variants: `subtle` (default) with a tinted background, and `plain` with no background and muted text.

<Wrapper>
	<Kbd variant="subtle">Esc</Kbd>
	<Kbd variant="plain">Esc</Kbd>
</Wrapper>

```tsx
<Kbd variant="subtle">Esc</Kbd>
<Kbd variant="plain">Esc</Kbd>
```

### Sizes

The `Kbd` component comes in three sizes: small, medium (default), and large.

<Wrapper>	
	<Kbd size="sm">Esc</Kbd>
	<Kbd size="md">Enter</Kbd>
	<Kbd size="lg">Space</Kbd>
</Wrapper>

```tsx
<Kbd size="sm">Esc</Kbd>
<Kbd size="md">Enter</Kbd>
<Kbd size="lg">Space</Kbd>
```

### Rendering platform specific action key

You can utilize `useActionKey` hook to get the platform specific action key. Returns "⌘" for MacOS and "Ctrl" for other platforms.

<Wrapper>
	<PlatformSpecificKbd />
</Wrapper>

```tsx
import { useActionKey } from "@dreamy-ui/react";

export function PlatformSpecificKbd() {
	const actionKey = useActionKey();
	
	return <Kbd>{actionKey} + K</Kbd>;
}
```
