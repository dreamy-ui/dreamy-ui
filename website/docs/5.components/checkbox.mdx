## Installation

```bash
bunx dreamy add checkbox
```

## Usage

Checkbox behavior and keyboard interaction are powered by [UI SDK Checkbox](https://ui-sdk.dev/docs/components/checkbox), with Dreamy recipes, `CheckboxGroup`, and indicator motion. Use `checked`, `defaultChecked`, and `onCheckedChange` for single checkboxes, and `value`, `defaultValue`, and `onValueChange` on `CheckboxGroup`.

Checkbox allows users to select multiple options from a list. Use it for multi-selection scenarios and boolean preferences.

<Wrapper>
	<Checkbox>Default</Checkbox>
</Wrapper>

```tsx
<Checkbox>
	Default
</Checkbox>
```

### Controlled

Use `checked` and `onCheckedChange` to control the checkbox.

<Wrapper>
	<ControlledCheckbox />
</Wrapper>

```tsx
export function ControlledCheckbox() {
    const [checked, setChecked] = useState(false);

    return (
        <>
            <Text>Selected: {checked ? "true" : "false"}</Text>
            <Checkbox
                checked={checked}
                onCheckedChange={(next) => setChecked(next === true)}
            >
                Controlled
            </Checkbox>
        </>
    );
}
```

### Checkbox group

Use `CheckboxGroup` to compose multiple checkboxes. Use `value` and `onValueChange` in `<CheckboxGroup />` to control the selected checkboxes. CheckboxGroup also accepts all the variant props of the Checkbox component.

Every Checkbox in the CheckboxGroup should have a unique `value` prop.

<Wrapper>
	<CheckboxGroupControl />
</Wrapper>

```tsx
function CheckboxGroupControl() {
    const [value, setValue] = useState<string[]>(["1"]);

    return (
        <>
            <Text>Selected: {value.join(", ")}</Text>
            <CheckboxGroup
                value={value}
                onValueChange={(next) => setValue(next)}
            >
                <Checkbox value="1">Option 1</Checkbox>
                <Checkbox value="2">Option 2</Checkbox>
                <Checkbox value="3">Option 3</Checkbox>
            </CheckboxGroup>
        </>
    );
}
```
