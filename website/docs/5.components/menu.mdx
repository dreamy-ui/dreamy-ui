### Top-layer positioning and UI SDK props

Menu keyboard navigation, ARIA attributes, submenus, and top-layer positioning are powered by [UI SDK Menu](https://ui-sdk.dev/docs/components/menu). Highlighted items expose `data-highlighted`. Configure placement with `positioning` on `Menu.Root` or `side`/`align`/`sideOffset` on `Menu.Content`, and use `container` only when targeting a custom container such as a shadow root or iframe.

<Wrapper>
    <Menu.Root>
        <Menu.Trigger>
            <Button>Open Menu</Button>
        </Menu.Trigger>
        <Menu.Content side="bottom" align="start">
            <Menu.Item>Add new</Menu.Item>
            <Menu.Item>Delete</Menu.Item>
        </Menu.Content>
    </Menu.Root>
</Wrapper>

```tsx
<Menu.Root>
    <Menu.Trigger>
        <Button>Open Menu</Button>
    </Menu.Trigger>
    <Menu.Content side="bottom" align="start">
        <Menu.Item>Add new</Menu.Item>
        <Menu.Item>Delete</Menu.Item>

</Menu.Root>
```

### Placement

You can change where the Menu appears using `positioning={{ placement }}` on `Menu.Root` (or `side` and `align` on `Menu.Content`). Use `icon` to place an icon at the start of an item and `command` to show a keybinding. Using `{actionKey}` in `command` automatically replaces it with the user's OS modifier key.

<Wrapper>
    <Menu.Root positioning={{ placement: "bottom-start" }}>
        <Menu.Trigger>
            <Button w={"fit-content"}>Open Menu</Button>
        </Menu.Trigger>

### Controlled

You can control the menu with `open` and `onOpenChange` on `Menu.Root` (for example with `useState`).

<Wrapper>
    <ControlledMenu />
</Wrapper>

```tsx
export function ControlledMenu() {
    const [open, setOpen] = useState(false);

    return (
        <Menu.Root
            open={open}
            onOpenChange={(nextOpen) => setOpen(nextOpen)}
        >
            <Text>{open ? "Open" : "Closed"}</Text>
            <Menu.Trigger>
                <Button>Open Menu</Button>
            </Menu.Trigger>
            <Menu.Content>
                <Menu.Item
                    icon={<LuWarehouse />}
```

### Adding logic to the commands

The `command` prop only displays the shortcut badge. You can use the `useEventListener` hook to handle keyboard shortcuts.

<Wrapper>
    <InteractiveMenu />
</Wrapper>

```tsx
export function InteractiveMenu() {
    const navigate = useNavigate();
    
    useEventListener("keydown", (event) => {
        if (!event[getActionKeyCode()]) return; // Making sure the ctrl/cmd key is pressed

        switch (event.key) {
            case "h": {
                event.preventDefault();
                navigate("/");
                alert("Homepage");
                break;
            }
            case "n": {
                event.preventDefault();
                alert("New");
                break;
            }
            case "a": {
                event.preventDefault();
                alert("Alarm");
                break;
            }
            case "b": {
                event.preventDefault();
                alert("Battery");
                break;
            }
            case "d": {
                event.preventDefault();
                alert("Delete");
                break;
            }
        }
    });

    return (
        <Menu.Root>
            <Menu.Trigger>
                <Button>Open Menu</Button>
            </Menu.Trigger>
            <Menu.Content>
                <Menu.Item
                    icon={<LuWarehouse />}
                    command="{actionKey} h"
                    render={<Link to="/" />}
                >
                    Homepage
                </Menu.Item>
                <Menu.Item
                    icon={<IoAdd />}
                    command="{actionKey} n"
                >
                    Add new
                </Menu.Item>
                <Menu.Item
                    icon={<LuAlarmClock />}
                    command="{actionKey} a"
                >
                    Set alarm
                </Menu.Item>
                <Menu.Item
                    icon={<LuBattery />}
                    command="{actionKey} b"
                >
                    Battery
                </Menu.Item>
                <Menu.Item
                    icon={<LuTrash />}
                    command="{actionKey} d"
                >
                    Delete
                </Menu.Item>
            </Menu.Content>
        </Menu.Root>
    );
}
```

### Nested Menus

Use `Menu.TriggerItem` to create sub-menus. Hover over the item or press `ArrowRight` to open the sub-menu, and `ArrowLeft` or `Escape` to close it and return focus to the parent.

<Wrapper>
    <Menu.Root>
        <Menu.Trigger>
            <Button w={"fit-content"}>Open Menu</Button>
        </Menu.Trigger>
        <Menu.Content>
            <Menu.Item icon={<IoAdd />}>Add new</Menu.Item>
            <Menu.Item icon={<LuAlarmClock />}>Set alarm</Menu.Item>
            <Menu.TriggerItem label="More options">
                <Menu.Content>
                    <Menu.Item icon={<LuBattery />}>Battery</Menu.Item>
                    <Menu.Item icon={<LuTrash />}>Delete</Menu.Item>
                    <Menu.TriggerItem label="Advanced">
                        <Menu.Content>
                            <Menu.Item>Export data</Menu.Item>
                            <Menu.Item>Import data</Menu.Item>
                            <Menu.Item>Reset settings</Menu.Item>
                        </Menu.Content>
                    </Menu.TriggerItem>
                </Menu.Content>
            </Menu.TriggerItem>
        </Menu.Content>
    </Menu.Root>
</Wrapper>

```tsx
<Menu.Root>
    <Menu.Trigger>
        <Button>Open Menu</Button>
    </Menu.Trigger>
    <Menu.Content>
        <Menu.Item icon={<IoAdd />}>Add new</Menu.Item>
        <Menu.Item icon={<LuAlarmClock />}>Set alarm</Menu.Item>
        {/* TriggerItem opens a sub-menu to the right */}
        <Menu.TriggerItem label="More options">
            <Menu.Content>
                <Menu.Item icon={<LuBattery />}>Battery</Menu.Item>
                <Menu.Item icon={<LuTrash />}>Delete</Menu.Item>
                {/* Sub-menus can be nested arbitrarily deep */}
                <Menu.TriggerItem label="Advanced">
                    <Menu.Content>
                        <Menu.Item>Export data</Menu.Item>
                        <Menu.Item>Import data</Menu.Item>
                        <Menu.Item>Reset settings</Menu.Item>
                    </Menu.Content>
                </Menu.TriggerItem>
            </Menu.Content>
        </Menu.TriggerItem>
    </Menu.Content>
</Menu.Root>
```

You can control the opening direction with the `positioning` prop:

```tsx
<Menu.TriggerItem label="More options" positioning={{ placement: "left-start" }}>
    <Menu.Content>
        <Menu.Item>Sub item</Menu.Item>
    </Menu.Content>
</Menu.TriggerItem>
```
