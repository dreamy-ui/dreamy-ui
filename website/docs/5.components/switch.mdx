## Installation

```bash
bunx dreamy add switch
```

## Usage

Switch behavior is powered by [UI SDK Switch](https://ui-sdk.dev/docs/react/components/switch). Keep the label the same in both states: the label names the setting, and the switch indicates whether it is on.

<Wrapper>
	<Switch>Airplane mode</Switch>
</Wrapper>

```tsx
<Switch>Airplane mode</Switch>
```

### Disabled & Read-Only

- `disabled` prevents focus and changes, and excludes the switch from form submission.
- `readOnly` keeps the switch focusable and submitted, while preventing user changes.

<Wrapper>
	<DisabledAndReadOnlySwitches />
</Wrapper>

```tsx
<VStack align="start" gap={4}>
	<Switch defaultChecked disabled>Security alerts</Switch>
	<Field.Root>
		<Field.Label>Encrypt backups</Field.Label>
		<Switch name="encrypt" defaultChecked readOnly />
		<Field.Hint>Your organization manages this setting.</Field.Hint>
	</Field.Root>
</VStack>
```

### Controlled & Controller

Use `checked` with `onCheckedChange` to control state, and `createSwitchController()` to toggle, set, read, or focus the switch from outside.

<Wrapper>
	<ControlledSwitch />
</Wrapper>

```tsx
function ControlledSwitch() {
	const [wifi] = useState(() => createSwitchController());
	const [checked, setChecked] = useState(true);

	return (
		<VStack align="start" gap={4}>
			<Button size="xs" variant="outline" onClick={() => wifi.toggle()}>
				Toggle
			</Button>
			<Switch
				checked={checked}
				controller={wifi}
				onCheckedChange={(next, details) => {
					setChecked(next);
					console.log(`${next ? "On" : "Off"} (${details.reason})`);
				}}
			>
				Wi-Fi
			</Switch>
		</VStack>
	);
}
```

### Form

Set `name` to include the switch in native `FormData`. When on, it submits `value` (default `"on"`); when off, it submits nothing. Form reset restores `defaultChecked`.

<Wrapper>
	<FormSwitch />
</Wrapper>

```tsx
<form onSubmit={handleSubmit}>
	<Fieldset.Root>
		<Fieldset.Legend>Email notifications</Fieldset.Legend>
		<Fieldset.Content>
			<Switch name="updates">Product updates</Switch>
			<Switch name="security" defaultChecked>Security alerts</Switch>
			<Switch name="digest" value="weekly" defaultChecked>Weekly digest</Switch>
		</Fieldset.Content>
	</Fieldset.Root>
	<Button type="submit">Save</Button>
	<Button type="reset">Reset</Button>
</form>
```

### Saving on Toggle

Call `details.cancel()` inside `onCheckedChange` to keep the current value while an async save runs, set `aria-busy`, show a `<Spinner />` via `icon`, and commit with `controller.setChecked(next, { reason: "imperative" })`.

<Wrapper>
	<AsyncSaveSwitch />
</Wrapper>

```tsx
<Switch
	aria-busy={saving}
	controller={backups}
	icon={saving ? <Spinner size="sm" /> : undefined}
	onCheckedChange={(next, details) => {
		if (details.reason === "imperative") return;
		details.cancel();
		if (pending.current) return;
		pending.current = true;
		setSaving(true);
		save(next).then(() => {
			pending.current = false;
			backups.setChecked(next, { reason: "imperative" });
			setSaving(false);
		});
	}}
>
	Automatic backups
</Switch>
```

## Styling & Data Attributes

- `[data-slot="switch"]` and `[data-part="thumb"]`:
  - `data-checked`: Present while on.
  - `data-unchecked`: Present while off.
  - `data-disabled`: Present when disabled.
  - `data-readonly`: Present when read-only.
  - `data-required`: Present when required.
  - `data-invalid`: Present on root and switch control when `isInvalid` or inside an invalid `Field.Root`.

## API Reference

| Prop | Type | Description |
| --- | --- | --- |
| `checked`, `defaultChecked` | `boolean` | Controlled or initial checked state |
| `onCheckedChange` | `(checked: boolean, details) => void` | Runs when toggled, reset, or set via controller |
| `disabled`, `readOnly`, `required` | `boolean` | Interactive and form validation states |
| `isInvalid` | `boolean` | Marks the switch as invalid for styling and ARIA |
| `name`, `value`, `form` | `string` | Native form participation |
| `icon` | `ReactNode \| ((state: SwitchThumbState) => ReactNode)` | Static or state-aware content inside the thumb |
| `thumbProps` | `MotionProps` | Motion props for the thumb content wrapper |
| `reduceMotion` | `boolean` | Disables thumb motion animation |
| `controller` | `SwitchController` | Imperative controller from `createSwitchController()` |
| `scheme`, `size` | Recipe variants | Color scheme and size (`sm`, `md`, `lg`) |
| `debug` | `boolean` | Logs state transitions in development |

Controller methods: `toggle(details?)`, `getChecked()`, `setChecked(checked, details?)`, `focus()`.
Change `details.reason` values: `press`, `reset`, `restore`, `imperative`.

## Accessibility & Keyboard

Follows the [WAI-ARIA Switch Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/switch/). Renders a `<button role="switch">` paired with a hidden native `<input type="checkbox">` for form submission.

| Key | Action |
| --- | --- |
| `Tab` | Move focus to the switch |
| `Space` | Toggle between on and off |
| `Enter` | Submits the surrounding form without toggling |
