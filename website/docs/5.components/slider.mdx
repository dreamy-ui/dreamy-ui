## Installation

```bash
bunx dreamy add slider
```

## Composition

Slider is powered by [UI SDK Slider](https://ui-sdk.dev/docs/react/components/slider) and composed from `Slider.Root`, `Slider.Value`, `Slider.Track`, `Slider.FilledTrack`, `Slider.Thumb`, and optional `Slider.Mark` elements.

```text
Slider.Root
├── Slider.Value
└── Slider.Track
    ├── Slider.FilledTrack
    ├── Slider.Thumb
    └── Slider.Mark
```

- **Slider.Root** holds the value, range bounds, formatting, and form state.
- **Slider.Value** renders an `<output>` showing the formatted value.
- **Slider.Track** wraps the interactive hit area (`SliderControl`) and rail (`SliderTrack`).
- **Slider.FilledTrack** fills the track up to the thumb.
- **Slider.Thumb** is the draggable thumb with a visually hidden `<input type="range">` inside it.
- **Slider.Mark** places optional markers at specific numeric values along the track.

For multi-thumb range sliders, see [Range Slider](/docs/components/range-slider).

### Field

Put the slider in a `Field.Root`. `Field.Label` names the thumb, `Field.Hint` describes it, and `Slider.Value` shows the formatted value beside the label. Clicking the label focuses the thumb.

<Wrapper>
	<FieldSlider />
</Wrapper>

```tsx
<Field.Root maxW="xs" w="full">
	<Slider.Root
		defaultValue={0.3}
		format={{ style: "percent" }}
		min={0}
		max={1}
		step={0.01}
	>
		<HStack justify="space-between">
			<Field.Label>Volume</Field.Label>
			<Slider.Value />
		</HStack>
		<Slider.Track>
			<Slider.FilledTrack />
			<Slider.Thumb />
		</Slider.Track>
	</Slider.Root>
	<Field.Hint>How loud notifications play.</Field.Hint>
</Field.Root>
```

### Controlled

Pass `value` and `onValueChange` to control the slider. Every change receives `(value, details)`, where `details.reason` tells you what triggered the change (`drag`, `track-press`, `step-key`, etc.). Call `details.cancel()` to keep the current value.

<Wrapper>
	<ControlledSlider />
</Wrapper>

```tsx
function ControlledSlider() {
	const [value, setValue] = useState(40);

	return (
		<VStack align="start" gap={4} maxW="sm" w="full">
			<Button size="xs" variant="outline" onClick={() => setValue(40)}>
				Reset
			</Button>
			<Field.Root w="full">
				<Slider.Root
					value={value}
					onValueChange={(nextValue, details) => {
						setValue(nextValue);
						console.log(`${nextValue} (${details.reason})`);
					}}
				>
					<HStack justify="space-between">
						<Field.Label>Volume</Field.Label>
						<Slider.Value />
					</HStack>
					<Slider.Track>
						<Slider.FilledTrack />
						<Slider.Thumb />
					</Slider.Track>
				</Slider.Root>
			</Field.Root>
		</VStack>
	);
}
```

### Controller

Create an imperative controller with `Slider.createSliderController()` to move the slider with `setValue()`, read it with `getValue()`, and focus the thumb with `focus()` from anywhere.

<Wrapper>
	<ControllerSlider />
</Wrapper>

```tsx
function ControllerSlider() {
	const [volume] = useState(() => Slider.createSliderController<number>());

	return (
		<VStack align="start" gap={4} maxW="sm" w="full">
			<Flex gap={2}>
				<Button size="xs" variant="outline" onClick={() => volume.setValue(0)}>
					Mute
				</Button>
				<Button size="xs" variant="outline" onClick={() => volume.setValue(volume.getValue() + 10)}>
					Louder
				</Button>
				<Button size="xs" variant="outline" onClick={() => volume.focus()}>
					Focus
				</Button>
			</Flex>
			<Field.Root w="full">
				<Slider.Root defaultValue={40} controller={volume}>
					<HStack justify="space-between">
						<Field.Label>Volume</Field.Label>
						<Slider.Value />
					</HStack>
					<Slider.Track>
						<Slider.FilledTrack />
						<Slider.Thumb />
					</Slider.Track>
				</Slider.Root>
			</Field.Root>
		</VStack>
	);
}
```

## Styling & Data Attributes

UI SDK sets CSS variables and state attributes on every part:

- **CSS variables**:
  - `--slider-indicator-start`: Indicator start position along the track in percent.
  - `--slider-indicator-size`: Indicator width/height in percent.
  - `--slider-thumb-position`: Thumb position along the track in percent.
- **Data attributes**:
  - `[data-slot="slider"]`, `[data-slot="slider-value"]`, `[data-slot="slider-control"]`, `[data-slot="slider-track"]`, `[data-slot="slider-indicator"]`, `[data-slot="slider-thumb"]`:
  - `data-orientation`: `"horizontal"` or `"vertical"`.
  - `data-disabled`: Present when disabled.
  - `data-dragging`: Present while dragging (`slider-thumb` scopes to the active thumb).
  - `data-invalid`: Present when `isInvalid` or `Field.Root invalid` is set.

## API Reference

### Slider.Root

| Prop | Type | Description |
| --- | --- | --- |
| `value` | `number` | Controlled value |
| `defaultValue` | `number` | Uncontrolled initial value (also used for form reset) |
| `onValueChange` | `(value: number, details: SliderValueChangeDetails) => void` | Fires on every step while changing |
| `onValueCommit` | `(value: number, details: SliderValueCommitDetails) => void` | Fires once when the interaction ends |
| `min`, `max`, `step` | `number` | Bounds and step size (defaults `0`, `100`, `1`) |
| `largeStep` | `number` | Step size for `PageUp`, `PageDown`, and `Shift` + Arrow |
| `orientation` | `"horizontal" \| "vertical"` | Slider axis (vertical grows upward) |
| `disabled`, `readOnly`, `required` | `boolean` | Interactive and form validation states |
| `isInvalid` | `boolean` | Marks the slider as invalid for styling |
| `name`, `form` | `string` | Native form field name and external form association |
| `format` | `Intl.NumberFormatOptions \| ((value: number) => string)` | Value formatting for `Slider.Value` and screen readers |
| `locale` | `string` | BCP 47 locale tag for number formatting |
| `controller` | `SliderController<number>` | Imperative controller from `Slider.createSliderController()` |
| `size` | `"sm" \| "md" \| "lg"` | Track and thumb preset size |
| `scheme` | `"primary" \| "secondary" \| "info" \| "success" \| "warning" \| "error" \| "none"` | Color scheme |
| `isReversed` | `boolean` | Places minimum value on the right (horizontal only) |
| `thumbSize` | `number` | Custom thumb diameter in pixels |
| `hideThumb` | `boolean` | Hides the thumb visually |
| `debug` | `boolean` | Logs state transitions in development |

### Controller & Reasons

`Slider.createSliderController<number>()` returns `{ getValue(), setValue(value, options?), focus(thumb?) }`.
Change `details.reason` values: `track-press`, `drag`, `step-key`, `accessibility-adjust`, `reset`, `restore`, `imperative`.

## Accessibility & Keyboard

Follows the [WAI-ARIA Slider Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/slider/). Each thumb wraps a native `<input type="range">` so screen readers announce formatted values and adjust them natively.

| Key | Action |
| --- | --- |
| `ArrowRight` / `ArrowUp` | Increase by `step` (reversed in RTL) |
| `ArrowLeft` / `ArrowDown` | Decrease by `step` (reversed in RTL) |
| `PageUp` / `PageDown` / `Shift` + Arrow | Move by `largeStep` |
| `Home` / `End` | Jump to `min` / `max` |
