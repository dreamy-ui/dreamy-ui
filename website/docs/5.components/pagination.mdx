## Installation

```bash
bunx dreamy add pagination
```

## Usage

Pagination is used to navigate through pages of content when you have too much data to display on a single page. Behavior and accessibility come from [UI SDK Pagination](https://ui-sdk.dev/docs/components/pagination), so `Pagination.Root` accepts `total`, `pageSize`, `pageCount`, `page`, `defaultPage`, `onPageChange`, `siblings`, `boundaries`, `getHref`, `controller`, and `translations`.

<Wrapper>
    <Pagination.Root total={100} pageSize={10} defaultPage={1}>
        <Pagination.PrevTrigger />
        <Pagination.Items />
        <Pagination.NextTrigger />
    </Pagination.Root>
</Wrapper>

```tsx
<Pagination.Root total={100} pageSize={10} defaultPage={1}>
    <Pagination.PrevTrigger />
    <Pagination.Items />
    <Pagination.NextTrigger />
</Pagination.Root>
```

### First and Last Triggers

Use `FirstTrigger` and `LastTrigger` to jump to the edges of the page range.

<Wrapper>
    <Pagination.Root total={100} pageSize={10} defaultPage={5}>
        <Pagination.FirstTrigger />
        <Pagination.PrevTrigger />
        <Pagination.Items />
        <Pagination.NextTrigger />
        <Pagination.LastTrigger />
    </Pagination.Root>
</Wrapper>

```tsx
<Pagination.Root total={100} pageSize={10} defaultPage={5}>
    <Pagination.FirstTrigger />
    <Pagination.PrevTrigger />
    <Pagination.Items />
    <Pagination.NextTrigger />
    <Pagination.LastTrigger />
</Pagination.Root>
```

### Custom Rendering

Use `Pagination.Context` to read pagination state (`page`, `pageCount`, `items`, `pageSize`, `total`) and build your own layout.

<Wrapper>
    <Pagination.Root total={100} pageSize={10} defaultPage={2}>
        <Pagination.Context>
            {(pagination) => (
                <>
                    <Pagination.PrevTrigger />
                    <span>Page {pagination.page} of {pagination.pageCount}</span>
                    <Pagination.NextTrigger />
                </>
            )}
        </Pagination.Context>
    </Pagination.Root>
</Wrapper>

```tsx
<Pagination.Root total={100} pageSize={10} defaultPage={2}>
    <Pagination.Context>
        {(pagination) => (
            <>
                <Pagination.PrevTrigger />
                <span>Page {pagination.page} of {pagination.pageCount}</span>
                <Pagination.NextTrigger />
            </>
        )}
    </Pagination.Context>
</Pagination.Root>
```

### Controlled Pagination

Control the pagination state using `page` and `onPageChange`. `onPageChange` receives `(page, details)`.

<Wrapper>
    <ControlledPagination />
</Wrapper>

```tsx
const [page, setPage] = useState(1);

<Pagination.Root
    total={100}
    page={page}
    pageSize={10}
    onPageChange={(nextPage) => setPage(nextPage)}
>
    <Pagination.PrevTrigger />
    <Pagination.Items />
    <Pagination.NextTrigger />
    <Pagination.PageText format="compact" ml={4} />
</Pagination.Root>
```

### Translations

Accessible labels default to `"Pagination"`, `"First page"`, `"Previous page"`, `"Next page"`, `"Last page"`, and `"Page N"`. Override any of them with `translations`.

```tsx
<Pagination.Root
    total={100}
    translations={{
        prevTriggerLabel: "Précédent",
        nextTriggerLabel: "Suivant",
        itemLabel: ({ page }) => `Page ${page}`
    }}
>
    <Pagination.PrevTrigger />
    <Pagination.Items />
    <Pagination.NextTrigger />
</Pagination.Root>
```

### Imperative Controller

Use `createPaginationController` (re-exported from the `pagination` module) to read or change pages imperatively with `setPage`, `next`, `previous`, `first`, and `last`.

```tsx
const [controller] = useState(createPaginationController);

<VStack align="flex-start" gap={3}>
    <HStack gap={2}>
        <Button size="sm" variant="outline" onClick={() => controller.previous()}>
            Prev
        </Button>
        <Button size="sm" variant="outline" onClick={() => controller.setPage(5)}>
            Jump to 5
        </Button>
        <Button size="sm" variant="outline" onClick={() => controller.next()}>
            Next
        </Button>
    </HStack>
    <Pagination.Root controller={controller} total={100} pageSize={10}>
        <Pagination.PrevTrigger />
        <Pagination.Items />
        <Pagination.NextTrigger />
    </Pagination.Root>
</VStack>
```
