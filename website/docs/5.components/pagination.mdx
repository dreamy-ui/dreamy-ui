## Installation

```bash
pnpm dreamy add pagination
```

## Usage

Pagination is used to navigate through pages of content when you have too much data to display on a single page. Behavior and accessibility come from [Ark UI Pagination](https://ark-ui.com/docs/components/pagination), so `Pagination.Root` accepts the same state props (`page`, `defaultPage`, `pageSize`, `defaultPageSize`, `onPageChange`, `onPageSizeChange`, `siblingCount`, `boundaryCount`, `translations`).

<Wrapper>
    <Pagination.Root count={100} pageSize={10} defaultPage={1}>
        <Pagination.PrevTrigger />
        <Pagination.Items />
        <Pagination.NextTrigger />
    </Pagination.Root>
</Wrapper>

```tsx
<Pagination.Root count={100} pageSize={10} defaultPage={1}>
    <Pagination.PrevTrigger />
    <Pagination.Items />
    <Pagination.NextTrigger />
</Pagination.Root>
```

### First and Last Triggers

Use `FirstTrigger` and `LastTrigger` to jump to the edges of the page range.

<Wrapper>
    <Pagination.Root count={100} pageSize={10} defaultPage={5}>
        <Pagination.FirstTrigger />
        <Pagination.PrevTrigger />
        <Pagination.Items />
        <Pagination.NextTrigger />
        <Pagination.LastTrigger />
    </Pagination.Root>
</Wrapper>

```tsx
<Pagination.Root count={100} pageSize={10} defaultPage={5}>
    <Pagination.FirstTrigger />
    <Pagination.PrevTrigger />
    <Pagination.Items />
    <Pagination.NextTrigger />
    <Pagination.LastTrigger />
</Pagination.Root>
```

### Automatic Ellipsis

The `Items` component automatically handles ellipsis placement based on the current page, `siblingCount`, and `boundaryCount`. This eliminates the need to manually manage which pages to show.

<Wrapper>
    <Pagination.Root count={200} pageSize={10} defaultPage={10} siblingCount={1}>
        <Pagination.PrevTrigger />
        <Pagination.Items />
        <Pagination.NextTrigger />
    </Pagination.Root>
</Wrapper>

```tsx
<Pagination.Root count={200} pageSize={10} defaultPage={10} siblingCount={1}>
    <Pagination.PrevTrigger />
    <Pagination.Items />
    <Pagination.NextTrigger />
</Pagination.Root>
```

### Custom Rendering

Use `Pagination.Context` to read the Ark pagination API (`page`, `pages`, `totalPages`, `pageRange`, `setPage`, `slice`, ...) and build your own layout.

<Wrapper>
    <Pagination.Root count={100} pageSize={10} defaultPage={2}>
        <Pagination.Context>
            {(pagination) => (
                <>
                    <Pagination.PrevTrigger />
                    <span>Page {pagination.page} of {pagination.totalPages}</span>
                    <Pagination.NextTrigger />
                </>
            )}
        </Pagination.Context>
    </Pagination.Root>
</Wrapper>

```tsx
<Pagination.Root count={100} pageSize={10} defaultPage={2}>
    <Pagination.Context>
        {(pagination) => (
            <>
                <Pagination.PrevTrigger />
                <span>Page {pagination.page} of {pagination.totalPages}</span>
                <Pagination.NextTrigger />
            </>
        )}
    </Pagination.Context>
</Pagination.Root>
```

### Controlled Pagination

You can control the pagination state using the `page` and `onPageChange` props. The `Items` component automatically updates based on the current page.

<Wrapper>
    <ControlledPagination />
</Wrapper>

```tsx
const [page, setPage] = useState(1);

<Pagination.Root
    count={100}
    page={page}
    pageSize={10}
    onPageChange={(details) => setPage(details.page)}
>
    <Pagination.PrevTrigger />
    <Pagination.Items />
    <Pagination.NextTrigger />
    <Pagination.PageText format="compact" ml={4} />
</Pagination.Root>
```

        <Pagination.PrevTrigger />

</Pagination.Root>

{/* Compact format: "3 of 10" */}

    <Pagination.PrevTrigger />
    <Pagination.Items />
    <Pagination.NextTrigger />
    <Pagination.PageText format="compact" ml={4} />

### Translations

Accessible labels default to "Pagination", "First page", "Previous page", "Next page", "Last page", and "Page N". Override any of them with `translations`.

```tsx
<Pagination.Root
    count={100}
    translations={{
        prevTriggerLabel: "Précédent",
        nextTriggerLabel: "Suivant",
        itemLabel: ({ page }) => `Page ${page}`
    }}
>
    <Pagination.PrevTrigger />
    <Pagination.Items />
    <Pagination.NextTrigger />
</Pagination.Root>
```

## Migrating from the hook-based Pagination

- `onPageChange` now receives `{ page, pageSize }`.
- `count` is optional (Ark defaults it to `1`), and `boundaryCount`, `defaultPageSize`, `onPageSizeChange`, and `translations` are new.
- `Pagination.Ellipsis` accepts an `index` (pass a unique one when rendering ellipses manually).
- `usePaginationRange` is no longer used by the component. Read `pages` from `Pagination.Context` instead.
