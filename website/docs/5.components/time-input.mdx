## Installation

```bash
bunx dreamy add time-input
```

## Usage

Click the control to open the time popover. Use up and down arrows to step the focused segment, and left and right arrows to move between segments.

<Wrapper>
    <TimeInput.AIO />
</Wrapper>

```tsx
<TimeInput.AIO />
```

### 12-hour format

Pass `hourCycle={12}` to show an AM/PM segment and a 1–12 hour wheel, or `hourCycle={24}` for 24-hour time.

<Wrapper>
    <TimeInput.AIO hourCycle={12} />
</Wrapper>

```tsx
<TimeInput.AIO hourCycle={12} />
```

### Granularity

Use `granularity` (`"hour"`, `"minute"`, or `"second"`) to choose the smallest unit displayed.

<Wrapper>
    <VStack alignItems="flex-start" gap={3}>
        <TimeInput.AIO defaultValue="09:00" granularity="hour" hourCycle={24} />
        <TimeInput.AIO defaultValue="14:30" granularity="minute" hourCycle={12} />
        <TimeInput.AIO defaultValue="14:30:45" granularity="second" hourCycle={24} />
    </VStack>
</Wrapper>

```tsx
<TimeInput.AIO defaultValue="09:00" granularity="hour" hourCycle={24} />
<TimeInput.AIO defaultValue="14:30" granularity="minute" hourCycle={12} />
<TimeInput.AIO defaultValue="14:30:45" granularity="second" hourCycle={24} />
```

### Controlled

Control the ISO time string (`"HH:mm"` or `"HH:mm:ss"`, or `null`) with `value` and `onValueChange`.

<Wrapper>
    <ControlledTimeInput />
</Wrapper>

```tsx
const [value, setValue] = useState<string | null>("14:30");

<TimeInput.AIO hourCycle={12} value={value} onValueChange={(next) => setValue(next)} />
```

### Sizes

Use the `size` prop to change the size of the trigger and wheel popover (`sm`, `md`, or `lg`).

<Wrapper>
    <HStack alignItems="flex-start" wrapped>
        <TimeInput.AIO size="sm" hourCycle={12} />
        <TimeInput.AIO size="md" hourCycle={12} />
        <TimeInput.AIO size="lg" hourCycle={12} />
    </HStack>
</Wrapper>

```tsx
<TimeInput.AIO size="sm" hourCycle={12} />
<TimeInput.AIO size="md" hourCycle={12} />
<TimeInput.AIO size="lg" hourCycle={12} />
```

### Variants

Use the `variant` prop to switch between `outline`, `solid`, and `filledOutline` trigger styles.

<Wrapper>
    <VStack alignItems="flex-start">
        <TimeInput.AIO variant="outline" hourCycle={12} />
        <TimeInput.AIO variant="solid" hourCycle={12} />
        <TimeInput.AIO variant="filledOutline" hourCycle={12} />
    </VStack>
</Wrapper>

```tsx
<TimeInput.AIO variant="outline" hourCycle={12} />
<TimeInput.AIO variant="solid" hourCycle={12} />
<TimeInput.AIO variant="filledOutline" hourCycle={12} />
```

### Steps

Use `minuteStep` and `secondStep` to snap wheel columns (for example every 5 minutes).

<Wrapper>
    <HStack alignItems="flex-start">
        <TimeInput.AIO defaultValue="09:00" hourCycle={12} minuteStep={5} />
        <TimeInput.AIO defaultValue="14:30:00" granularity="second" secondStep={15} />
    </HStack>
</Wrapper>

```tsx
<TimeInput.AIO defaultValue="09:00" hourCycle={12} minuteStep={5} />
<TimeInput.AIO defaultValue="14:30:00" granularity="second" secondStep={15} />
```

### Compound API

Compose the parts yourself when you need custom layout.

<Wrapper>
    <TimeInput.Root defaultValue="16:45:00" granularity="second" hourCycle={12}>
        <TimeInput.Trigger />
        <TimeInput.Content>
            <TimeInput.Columns />
        </TimeInput.Content>
    </TimeInput.Root>
</Wrapper>

```tsx
<TimeInput.Root defaultValue="16:45:00" granularity="second" hourCycle={12}>
    <TimeInput.Trigger />
    <TimeInput.Content>
        <TimeInput.Columns />
    </TimeInput.Content>
</TimeInput.Root>
```

### With Field

Combine `TimeInput` with `Field` to associate a label, hint, and validation state.

<Wrapper>
    <Field.Root>
        <Field.Label>Appointment time</Field.Label>
        <TimeInput.AIO hourCycle={12} name="appointmentTime" />
        <Field.Hint>Scroll the wheels or type each segment</Field.Hint>
    </Field.Root>
</Wrapper>

```tsx
<Field.Root>
    <Field.Label>Appointment time</Field.Label>
    <TimeInput.AIO hourCycle={12} name="appointmentTime" />
    <Field.Hint>Scroll the wheels or type each segment</Field.Hint>
</Field.Root>
```
