## Installation

```bash
bunx dreamy add pin-input
```

## Usage

`PinInput` wraps [UI SDK OTPInput](https://ui-sdk.dev/docs/components/otp-input) so screen readers and mobile autofill see a single real input while rendering individual `PinInput.Field` slots.

<Wrapper>
    <PinInput.Root aria-label="Verification code" defaultValue="123">
        <PinInput.Field />
        <PinInput.Field />
        <PinInput.Field />
    </PinInput.Root>
</Wrapper>

```tsx
<PinInput.Root aria-label="Verification code" defaultValue="123">
    <PinInput.Field />
    <PinInput.Field />
    <PinInput.Field />
</PinInput.Root>
```

### Controlled

Use `value` and `onValueChange` to control the code, `onValueCommit` to react when every slot is filled, or `createOTPInputController` for imperative control.

```tsx
function ControlledPinInput() {
    const [pin, setPin] = useState("2137");

    return (
        <PinInput.Root
            aria-label="Verification code"
            value={pin}
            onValueChange={(next) => setPin(next)}
            onValueCommit={(code) => console.log("Submitted:", code)}
        >
            <PinInput.Field />
            <PinInput.Field />
            <PinInput.Field />
            <PinInput.Field />
        </PinInput.Root>
    );
}
```
