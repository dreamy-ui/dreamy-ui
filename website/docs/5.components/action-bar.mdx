## Installation

```bash
bunx dreamy add action-bar
```

## Usage

Action Bar displays a set of actions at the bottom of the screen, typically used for bulk operations on selected items. Powered by UI SDK `Toolbar` with `open`, `defaultOpen`, `onOpenChange`, and `closeOnEscape`.

<Wrapper>
  <ControlledActionBar />
</Wrapper>

```tsx
function ControlledActionBar() {
	const [open, setOpen] = useState(false);

	return (
		<>
			<Switch size="sm" checked={open} onCheckedChange={setOpen}>
				Show Action Bar
			</Switch>

			<ActionBar.Root open={open} onOpenChange={setOpen}>
				<ActionBar.Content>
					<ActionBar.SelectionTrigger>2 items selected</ActionBar.SelectionTrigger>
					<ActionBar.Separator />
					<Button size="sm" variant="outline" rightIcon={<LuTrash />}>
						Delete
					</Button>
					<Button size="sm" variant="outline" rightIcon={<LuShare />}>
						Share
					</Button>
				</ActionBar.Content>
			</ActionBar.Root>
		</>
	);
}
```

### Uncontrolled Usage

You can use the action bar in an uncontrolled mode with `defaultOpen`.

```tsx
<ActionBar.Root defaultOpen onOpenChange={(open) => console.log("open:", open)}>
  <ActionBar.Content>
    <ActionBar.SelectionTrigger>1 selected</ActionBar.SelectionTrigger>
    <ActionBar.Separator />
    <Button size="sm" variant="outline">
      Action
    </Button>
    <ActionBar.CloseTrigger />
  </ActionBar.Content>
</ActionBar.Root>
```
