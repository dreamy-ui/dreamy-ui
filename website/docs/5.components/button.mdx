## Installation

```bash
bunx dreamy add button
```

## Usage

Button is used to trigger an action or event, such as submitting a form or opening a dialog. It provides various styling options and supports different variants.

<Wrapper>
	<Button w="fit-content">Button</Button>
</Wrapper>

```tsx
<Button>Button</Button>
```

You can change the variant of the Button by using the `variant` prop.

### Color

When using `solid`, `outline`, `filledOutline` and `ghost` variants, the button color will follow the current color scheme.

For `solid` and `ghost` variants, you can just use `color` property, it will work the same. However for `outline` and `filledOutline` variants, you need to use only `scheme` property.

<Wrapper>
	<Flex wrapped gap={2}>
		<Button variant="solid" scheme="success">Solid success</Button>
		<Button variant="outline" scheme="warning">Outline warning</Button>
		<Button variant="ghost" scheme="error">Ghost error</Button>
	</Flex>
</Wrapper>

```tsx
<Flex wrapped gap={2}>
  <Button variant="solid" scheme="success">Solid success</Button>
  <Button variant="outline" scheme="warning">Outline warning</Button>
  <Button variant="ghost" scheme="error">Ghost error</Button>
</Flex>
```

### Success State

Use the `isSuccess` prop to confirm a completed action. The Button switches to the success color, whatever its `variant` or `scheme`, and draws an animated check icon. The Button keeps its width and stays clickable. If `isLoading` and `isSuccess` are both set, the loading state is shown.

<Wrapper>
	<Button w="fit-content" isSuccess variant="primary">Save</Button>
</Wrapper>

```tsx
<Button isSuccess variant="primary">Save</Button>
```

**With label**

Use `successText` to replace the label while the Button is successful. It also becomes the Button's accessible name.

<Wrapper>
	<Button w="fit-content" isSuccess successText="Saved" variant="outline">Save</Button>
</Wrapper>

```tsx
<Button isSuccess successText="Saved" variant="outline">Save</Button>
```

**Custom icon**

Use `successIcon` to replace the default animated check icon.

<Wrapper>
	<Button w="fit-content" isSuccess successText="Published" successIcon={<PiConfetti />} variant="ghost">Publish</Button>
</Wrapper>

```tsx
<Button isSuccess successText="Published" successIcon={<PiConfetti />} variant="ghost">Publish</Button>
```

**Loading to success**

A common pattern is to show the loading state while a request is running, then show the success state for a moment.

<Wrapper>
	<SuccessFlowButton />
</Wrapper>

```tsx
export function SuccessFlowButton() {
    const [status, setStatus] = useState<"idle" | "loading" | "success">("idle");

    async function handleClick() {
        setStatus("loading");
        await saveChanges();
        setStatus("success");
        setTimeout(() => setStatus("idle"), 2000);
    }

    return (
        <Button
            isLoading={status === "loading"}
            isSuccess={status === "success"}
            loadingText="Saving"
            onClick={handleClick}
            successText="Saved"
            variant="primary"
        >
            Save changes
        </Button>
    );
}
```

The check animation follows the `motionVariants` and `reduceMotion` settings from `DreamyProvider`. You can override it with the `buttonSuccessIcon` motion variant. The visual state is not announced to screen readers by itself, so for important actions, also confirm the result with a toast or a live region.

### Disable ripple

You can disable the ripple effect of the Button by using the `disableRipple` prop. This can be provided in `DreamyProvider` as a global setting.

<Wrapper>
	<Button w="fit-content" disableRipple>Disabled Ripple</Button>
</Wrapper>

```tsx
<Button w="fit-content" disableRipple>Disabled Ripple</Button>
```

### As Link

Often you need to use a Button as a link. You can do this by using the `render` prop or `asChild`.

<Wrapper>
	<Flex wrapped gap={2}>
		<Button render={<ReactRouterLink to="/" />}>Home</Button>
		<Button asChild>
			<ReactRouterLink to="/">Home</ReactRouterLink>
		</Button>
	</Flex>
</Wrapper>

```tsx
<Button render={<Link to="/" />}>Home</Button>
<Button asChild>
	<Link to="/">Home</Link>
</Button>
```

### Different active state

If you dislike the default ripple effect, you can customize the button recipe to use a different active state. For example scale the button when it's pressed.

				Press me
