## Installation

```bash
bunx dreamy add range-slider
```

## Composition

Range Slider is powered by [UI SDK Slider](https://ui-sdk.dev/docs/react/components/slider) and composed from `RangeSlider.Root`, `RangeSlider.Value`, `RangeSlider.Track`, `RangeSlider.FilledTrack`, two or more `RangeSlider.Thumb` elements (each with an `index` starting at `0`), and optional `RangeSlider.Mark` elements.

```text
RangeSlider.Root
├── RangeSlider.Value
└── RangeSlider.Track
    ├── RangeSlider.FilledTrack
    ├── RangeSlider.Thumb (index={0})
    ├── RangeSlider.Thumb (index={1})
    └── RangeSlider.Mark
```

- Give each thumb its own `index` (`0`, `1`, ...) and its own `aria-label` (or pass an array of labels to `aria-label` on `RangeSlider.Root`).
- Name the group with `Field.Label` or a string `aria-label` on `RangeSlider.Root`.
- For single-thumb sliders, see [Slider](/docs/components/slider).

### Range & Formatting

Pass an array to `defaultValue` or `value` and render one `RangeSlider.Thumb` per number. `RangeSlider.Value` formats the range joined with an en dash.

<Wrapper>
	<PriceRangeSlider />
</Wrapper>

```tsx
<Field.Root maxW="xs" w="full">
	<RangeSlider.Root
		defaultValue={[25, 50]}
		step={5}
		format={{
			style: "currency",
			currency: "USD",
			maximumFractionDigits: 0
		}}
	>
		<HStack justify="space-between">
			<Field.Label>Price</Field.Label>
			<RangeSlider.Value />
		</HStack>
		<RangeSlider.Track>
			<RangeSlider.FilledTrack />
			<RangeSlider.Thumb index={0} aria-label="Minimum price" />
			<RangeSlider.Thumb index={1} aria-label="Maximum price" />
		</RangeSlider.Track>
	</RangeSlider.Root>
</Field.Root>
```

### Multiple Thumbs

Any number of thumbs works the same way. They never pass each other, and pressing the track moves the nearest thumb.

<Wrapper>
	<MultipleThumbsSlider />
</Wrapper>

```tsx
const thumbs = ["Low", "Medium", "High"];

<Field.Root maxW="xs" w="full">
	<RangeSlider.Root
		defaultValue={[10, 20, 70]}
		step={10}
		format={{ style: "unit", unit: "percent" }}
	>
		<HStack justify="space-between">
			<Field.Label>Alert thresholds</Field.Label>
			<RangeSlider.Value />
		</HStack>
		<RangeSlider.Track>
			<RangeSlider.FilledTrack />
			{thumbs.map((label, index) => (
				<RangeSlider.Thumb key={label} index={index} aria-label={label} />
			))}
		</RangeSlider.Track>
	</RangeSlider.Root>
</Field.Root>
```

### Distance Between Thumbs

Set `minStepsBetweenThumbs` to keep neighbouring thumbs at least that many steps apart. `Home` and `End` also stop at the minimum allowed distance from a neighbour.

<Wrapper>
	<MinStepsRangeSlider />
</Wrapper>

```tsx
const formatTime = (minutes: number) =>
	`${Math.floor(minutes / 60)}:${String(minutes % 60).padStart(2, "0")}`;

<Field.Root maxW="xs" w="full">
	<RangeSlider.Root
		defaultValue={[540, 1020]}
		min={0}
		max={1440}
		step={15}
		minStepsBetweenThumbs={16}
		format={formatTime}
	>
		<HStack justify="space-between">
			<Field.Label>Opening hours</Field.Label>
			<RangeSlider.Value />
		</HStack>
		<RangeSlider.Track>
			<RangeSlider.FilledTrack />
			<RangeSlider.Thumb index={0} aria-label="Opens" />
			<RangeSlider.Thumb index={1} aria-label="Closes" />
		</RangeSlider.Track>
	</RangeSlider.Root>
</Field.Root>
```

### Controlled

Pass `value` and `onValueChange` to control the range. Every change passes `(value, details)` with `details.reason` and `details.thumb`. Call `details.cancel()` to reject a change.

<Wrapper>
	<ControlledRangeSlider />
</Wrapper>

```tsx
function ControlledRangeSlider() {
	const [value, setValue] = useState<[number, number]>([0.3, 0.7]);

	return (
		<VStack align="start" gap={4} maxW="sm" w="full">
			<Button size="xs" variant="outline" onClick={() => setValue([0.3, 0.7])}>
				Reset
			</Button>
			<Field.Root w="full">
				<RangeSlider.Root
					value={value}
					onValueChange={(next) => setValue(next)}
					min={0}
					max={1}
					step={0.1}
				>
					<HStack justify="space-between">
						<Field.Label>Temperature</Field.Label>
						<RangeSlider.Value />
					</HStack>
					<RangeSlider.Track>
						<RangeSlider.FilledTrack />
						<RangeSlider.Thumb index={0} aria-label="Minimum temperature" />
						<RangeSlider.Thumb index={1} aria-label="Maximum temperature" />
					</RangeSlider.Track>
				</RangeSlider.Root>
			</Field.Root>
		</VStack>
	);
}
```

### Saving on Commit

Use `onValueCommit` to persist the committed range once the pointer lifts, key releases, or screen reader finishes adjusting.

<Wrapper>
	<CommitRangeSlider />
</Wrapper>

```tsx
<RangeSlider.Root
	defaultValue={[20, 80]}
	onValueCommit={(value, details) => console.log(`Saved ${value.join(" – ")} (${details.reason})`)}
>
	<RangeSlider.Track>
		<RangeSlider.FilledTrack />
		<RangeSlider.Thumb index={0} aria-label="Minimum" />
		<RangeSlider.Thumb index={1} aria-label="Maximum" />
	</RangeSlider.Track>
</RangeSlider.Root>
```

### Controller

Create a controller with `RangeSlider.createSliderController<[number, number]>()` to read, set, or focus a specific thumb (`controller.focus(0)` / `controller.focus(1)`) from outside the slider.

<Wrapper>
	<ControllerRangeSlider />
</Wrapper>

```tsx
const [controller] = useState(() => RangeSlider.createSliderController<[number, number]>());

<Button onClick={() => controller.setValue([0, 100])}>Expand</Button>
<Button onClick={() => controller.focus(1)}>Focus Max</Button>
```

### Custom Rendering

Pass function `children` or `render` to `RangeSlider.Value` and `RangeSlider.Thumb` to render custom labels or live thumb badges using `state.thumbValue` and `state.percent`.

<Wrapper>
	<CustomRenderingRangeSlider />
</Wrapper>

```tsx
<RangeSlider.Root defaultValue={[25, 75]}>
	<RangeSlider.Value>{(state) => `${state.text}%`}</RangeSlider.Value>
	<RangeSlider.Track>
		<RangeSlider.FilledTrack />
		<RangeSlider.Thumb index={0} aria-label="Minimum">
			{(state) => <span>{state.thumbValue}</span>}
		</RangeSlider.Thumb>
		<RangeSlider.Thumb index={1} aria-label="Maximum">
			{(state) => <span>{state.thumbValue}</span>}
		</RangeSlider.Thumb>
	</RangeSlider.Track>
</RangeSlider.Root>
```

## Styling & Data Attributes

- **CSS variables**: `--slider-indicator-start`, `--slider-indicator-size`, `--slider-thumb-position`.
- **Data attributes**: `data-orientation`, `data-disabled`, `data-dragging`, `data-invalid`, and `data-index` on each `[data-slot="slider-thumb"]`.

## API Reference

`RangeSlider.Root` accepts all UI SDK `SliderOptions<Value>` (where `Value extends number[]`, defaulting to `[number, number]`) including `value`, `defaultValue`, `onValueChange`, `onValueCommit`, `min`, `max`, `step`, `largeStep`, `minStepsBetweenThumbs`, `orientation`, `disabled`, `readOnly`, `required`, `name`, `form`, `format`, `locale`, `controller`, and `debug`, plus Dreamy presentation props `size`, `scheme`, `isReversed`, `thumbSize`, and `isInvalid`.

## Accessibility & Keyboard

Follows the [WAI-ARIA Multi-Thumb Slider Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/slider-multithumb/).

| Key | Action |
| --- | --- |
| `Tab` / `Shift+Tab` | Move between thumbs in order |
| `ArrowRight` / `ArrowUp` | Increase focused thumb by `step` |
| `ArrowLeft` / `ArrowDown` | Decrease focused thumb by `step` |
| `PageUp` / `PageDown` / `Shift` + Arrow | Move focused thumb by `largeStep` |
| `Home` / `End` | Move as far as `min` / `max` or neighbouring thumb allows |
