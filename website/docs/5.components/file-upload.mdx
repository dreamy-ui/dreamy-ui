## Installation

```bash
bunx dreamy add file-upload
```

## Usage

File Upload is a compound component powered by [UI SDK FileInput](https://ui-sdk.dev/docs/components/file-input), supporting file selection, drag and drop, paste, previews, and validation. It also supports `Field.Root` integration as well as `disabled`, `required`, and `invalid` states.

<Wrapper>
    <FileUpload.Root maxW="sm">
        <FileUpload.Trigger render={<Button variant="outline" />}>
            Upload file
        </FileUpload.Trigger>
        <FileUpload.List />
    </FileUpload.Root>
</Wrapper>

```tsx
<FileUpload.Root maxW="sm">
    <FileUpload.Trigger render={<Button variant="outline" />}>
        Upload file
    </FileUpload.Trigger>
    <FileUpload.List />
</FileUpload.Root>
```

### Accepted Files

Define accepted file types using the `accept` prop with MIME types or file extensions.

<Wrapper>
    <FileUpload.Root accept={["image/png"]} maxW="sm">
        <FileUpload.Trigger render={<Button variant="outline" />}>
            Upload PNG
        </FileUpload.Trigger>
        <FileUpload.List />
    </FileUpload.Root>
</Wrapper>

```tsx
<FileUpload.Root accept={["image/png"]} maxW="sm">
    <FileUpload.Trigger render={<Button variant="outline" />}>
        Upload PNG
    </FileUpload.Trigger>
    <FileUpload.List />
</FileUpload.Root>
```

                Browse files

### File Size Validation

Use `maxSize` and `minSize` (in bytes) with `onReject` to handle rejected files.

<Wrapper>
    <FileUpload.Root
        maxSize={3 * 1024 * 1024}
        maxW="sm"
        onReject={(rejected) => {
            toast({
                title: "File rejected",
                description: rejected.map((entry) => `${entry.file.name}: ${entry.reasons.join(", ")}`).join(", "),
                status: "error"
            });
        }}
    >
        <FileUpload.Trigger render={<Button variant="outline" />}>
            Upload file (max 3MB)
        </FileUpload.Trigger>
        <FileUpload.List showSize />
    </FileUpload.Root>
</Wrapper>

```tsx
<FileUpload.Root
    maxSize={3 * 1024 * 1024}
    maxW="sm"

        });
    }}
>
    <FileUpload.Trigger render={<Button variant="outline" />}>
        Upload file (max 3MB)
    </FileUpload.Trigger>

```

### Custom List

Build a custom file list with `FileUpload.Context`, `FileUpload.ItemGroup`, `FileUpload.Item`, `FileUpload.ItemPreviewImage`, and `FileUpload.ItemDeleteTrigger`.

<Wrapper>
    <FileUploadCustomList />
</Wrapper>

```tsx
<FileUpload.Root accept={["image/*"]} maxFiles={5} maxW="sm" multiple>
    <FileUpload.Trigger render={<Button variant="outline" />}>
        Upload Images
    </FileUpload.Trigger>
    <FileUpload.Context>
        {({ files }) => {
            if (files.length === 0) return null;

            return (
                <FileUpload.ItemGroup>
                    {files.map((file, index) => (
                        <FileUpload.Item
                            key={`${file.name}-${index}`}
                            file={file}
                            bg="transparent"
                            boxSize="20"
                            overflow="hidden"
                            p="2"
                            position="relative"
                            w="auto"
                        >
                            <FileUpload.ItemPreviewImage file={file} />
                            <Flex position="absolute" right="1" top="1">
                                <FileUpload.ItemDeleteTrigger
                                    boxSize="5"
                                    file={file}
                                    rounded="full"
                                />
                            </Flex>
                        </FileUpload.Item>
                    ))}
                </FileUpload.ItemGroup>
            );
        }}
    </FileUpload.Context>
</FileUpload.Root>
```

### Controlled & Imperative Controller

Control selected files with `value`, `defaultValue`, and `onValueChange`, or use `createFileInputController` (re-exported from the `file-upload` module) to open the picker, add or remove files, and clear the list imperatively.

```tsx
const [controller] = useState(createFileInputController);

<VStack align="flex-start" gap={3}>
    <HStack gap={2}>
        <Button size="sm" variant="outline" onClick={() => controller.open()}>
            Open Picker
        </Button>
        <Button size="sm" variant="outline" onClick={() => controller.clear()}>
            Clear
        </Button>
    </HStack>
    <FileUpload.Root
        controller={controller}
        multiple
        onValueChange={(files) => console.log(files)}
    >
        <FileUpload.Trigger render={<Button variant="outline" />}>
            Upload files
        </FileUpload.Trigger>
        <FileUpload.List showSize clearable />
    </FileUpload.Root>
</VStack>
```
