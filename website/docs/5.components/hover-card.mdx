## Installation

```bash
bunx dreamy add hover-card
```

## Usage

Hover Card uses [UI SDK Hover Card](https://ui-sdk.dev/docs/components/hover-card) for open/close timing, focus, top-layer positioning, and dismissal. Dreamy provides recipes and the compound API. Use `open`, `defaultOpen`, and `onOpenChange` for controlled state. `hasArrow` defaults to `true` on the root.

Hover over the username to see a profile card.

### Controlled

Use `open` and `onOpenChange` to control the hover card programmatically.

<Wrapper>
    <ControlledHoverCard />
</Wrapper>

```tsx
export function ControlledHoverCard() {
    const [open, setOpen] = useState(false);

    return (
        <VStack align="flex-start" gap={4}>
            <Button
                size="sm"
                variant="outline"
                onClick={() => setOpen(!open)}
            >
                {open ? "Close" : "Open"} hover card
            </Button>
            <HoverCard.Root
                open={open}
                onOpenChange={(nextOpen) => setOpen(nextOpen)}
            >
                <HoverCard.Trigger>
                    <Button variant="link">@dreamy_ui</Button>
                </HoverCard.Trigger>
                <HoverCard.Content>
                    <HoverCard.Body>
                        <Text color="fg.medium" fontSize="sm">
                            Controlled hover card content.
                        </Text>
                    </HoverCard.Body>
                </HoverCard.Content>
            </HoverCard.Root>
        </VStack>
    );
}
```
