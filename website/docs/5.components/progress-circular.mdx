## Installation

```bash
bunx dreamy add progress-circular
```

## Usage

Progress Circular is powered by [UI SDK Progress](https://ui-sdk.dev/docs/react/components/progress). Use `value` between `min` and `max`, and enable `showValueLabel` or `label` to display formatted progress and name the control.

<Wrapper>
	<ProgressCircular value={69} showValueLabel label="Loading" />
</Wrapper>

```tsx
<ProgressCircular value={69} showValueLabel label="Loading" />
```

### Indeterminate

Pass `value={null}` (or omit `value`, or pass `isIndeterminate`) to show an indeterminate spinning indicator. Customize the spin speed with `speed` (default `"1.5s"`).

<Wrapper>
	<ProgressCircular value={null} label="Connecting" />
</Wrapper>

```tsx
<ProgressCircular value={null} label="Connecting" />
```

### Changing the Value

Pass the latest `value` as your task progresses. The underlying UI SDK root updates `data-progressing` and `data-complete` automatically.

<Wrapper>
	<InteractiveProgressCircular />
</Wrapper>

```tsx
<ProgressCircular
	label="Uploading photos"
	showValueLabel
	size="lg"
	value={(uploaded / total) * 100}
/>
```

### Show Value Label, Format & Locale

When `showValueLabel` is `true`, `ProgressCircular` renders UI SDK's `ProgressValue` in the center of the ring. Without `valueLabel`, it formats the value automatically using `format` and `locale`.

<Wrapper>
	<FormatAndLocaleProgressCircular />
</Wrapper>

```tsx
<Flex gap={6} wrap="wrap">
	<ProgressCircular
		format={{ style: "currency", currency: "USD", maximumFractionDigits: 0 }}
		label="Budget"
		showValueLabel
		size="lg"
		value={69}
	/>
	<ProgressCircular
		format={{ style: "unit", unit: "percent" }}
		label="CPU"
		showValueLabel
		size="lg"
		value={42}
	/>
	<ProgressCircular
		label="Synchronisierung"
		locale="de-DE"
		showValueLabel
		size="lg"
		value={40}
	/>
</Flex>
```

### Value Label

Use `getValueLabel` to give screen readers extra context while keeping the visible `valueLabel` compact inside the ring.

<Wrapper>
	<ValueLabelProgressCircular />
</Wrapper>

```tsx
<ProgressCircular
	getValueLabel={(value, details) =>
		`${value} of ${details.max} files, ${details.formatted}`
	}
	label="Copying files"
	max={12}
	showValueLabel
	size="lg"
	value={3}
	valueLabel="3/12"
/>
```

### Label

Pass `label` to render an accessible `ProgressLabel` below the ring that automatically names the progressbar.

<Wrapper>
	<ProgressCircular label="Downloading..." value={69} />
</Wrapper>

```tsx
<ProgressCircular label="Downloading..." value={69} />
```

## Styling & Data Attributes

- **CSS variable**: `--progress-value` holds the percentage between `min` and `max`.
- **Data attributes**: `data-indeterminate`, `data-progressing`, `data-complete`, and `data-disabled`.

## API Reference

| Prop | Type | Description |
| --- | --- | --- |
| `value` | `number \| null` | Current value between `min` and `max`, or `null` for indeterminate |
| `min`, `max` | `number` | Range bounds (defaults `0`, `100`) |
| `isIndeterminate` | `boolean` | Forces indeterminate mode |
| `label` | `string` | Label rendered below the ring via `ProgressLabel` |
| `showValueLabel` | `boolean` | Shows formatted `ProgressValue` inside the ring |
| `valueLabel` | `string` | Overrides the visible value text inside the ring |
| `format` | `NumberFormat` | `Intl.NumberFormatOptions` or formatter function |
| `locale` | `string` | BCP 47 locale tag |
| `getValueLabel` | `(value: number \| null, details: GaugeLabelDetails<number \| null>) => string` | Screen reader announcement formatter |
| `speed` | `string` | Indeterminate spin speed (default `"1.5s"`) |
| `disabled` | `boolean` | Marks the indicator disabled |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | Ring diameter and stroke thickness |
| `scheme` | `"primary" \| "secondary" \| "info" \| "success" \| "warning" \| "error" \| "none"` | Color scheme |
| `debug` | `boolean` | Logs state transitions in development |

## Accessibility

Name the indicator with `label` or `aria-label`. The decorative SVG ring carries `aria-hidden="true"`, while the root exposes `role="progressbar"` with `aria-valuemin`, `aria-valuemax`, `aria-valuenow`, and `aria-valuetext`.
