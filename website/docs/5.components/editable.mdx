## Installation

```bash
bunx dreamy add editable
```

## Usage

Editable displays a read-only preview that switches to a [UI SDK Editable](https://ui-sdk.dev/docs/components/editable) input when activated. The placeholder is shown in the preview when the value is empty.

<Wrapper>
    <Editable.Root defaultValue="Meow" placeholder="Enter an animal sound">
        <Editable.Preview />
        <Editable.Input />
        <HStack>
            <Editable.EditButton />
            <Editable.SubmitButton />
            <Editable.CancelButton />
        </HStack>
    </Editable.Root>
</Wrapper>

```tsx
<Editable.Root defaultValue="Meow" placeholder="Enter an animal sound">
    <Editable.Preview />
    <Editable.Input />
    <HStack>
        <Editable.EditButton />
        <Editable.SubmitButton />
        <Editable.CancelButton />
    </HStack>
</Editable.Root>
```

### Variants

Use `variant` to change how editability is signaled. `plain` (default) is text-only; `soft` adds subtle hover and focus feedback.

<Wrapper>
    <HStack alignItems="flex-start" gap={8}>
        <Editable.Root defaultValue="Plain" placeholder="Enter text" variant="plain">
            <Editable.Preview />
            <Editable.Input />
        </Editable.Root>
        <Editable.Root defaultValue="Soft" placeholder="Enter text" variant="soft">
            <Editable.Preview />
            <Editable.Input />
        </Editable.Root>
    </HStack>
</Wrapper>

### Activation Mode

Set `activationMode="dblclick"` to require double-clicking the preview, or `"none"` to enter edit mode only via `Editable.EditButton`.

<Wrapper>
    <Editable.Root defaultValue="Meow" placeholder="Enter an animal sound" activationMode="dblclick">
        <Editable.Preview />
        <Editable.Input />
    </Editable.Root>
</Wrapper>

```tsx
<Editable.Root defaultValue="Meow" placeholder="Enter an animal sound" activationMode="dblclick">
    <Editable.Preview />
    <Editable.Input />
</Editable.Root>
```

### Controlled

Use `value` and `onValueChange` (plus `onValueCommit` and `onValueRevert`) to control the editable value.

<Wrapper>
    <ControlledEditable />
</Wrapper>

```tsx
function ControlledEditable() {
    const [value, setValue] = useState("Meow");

    return (
        <Editable.Root value={value} onValueChange={setValue}>
            <Editable.Preview />
            <Editable.Input />
            <HStack>
                <Editable.EditButton />
                <Editable.SubmitButton />
                <Editable.CancelButton />
            </HStack>
        </Editable.Root>
    );
}
```

### Render-prop State

Pass a render function to `Editable.Root` to read the current `editing` state and imperative helpers (`edit`, `submit`, `cancel`).

<Wrapper>
    <Editable.Root defaultValue="Meow" placeholder="Enter an animal sound">
        {({ editing }) => (
            <>
                <Text>editing: {editing ? "true" : "false"}</Text>
                <Editable.Preview />
                <Editable.Input />
                <HStack>
                    <Editable.EditButton />
                    <Editable.SubmitButton />
                    <Editable.CancelButton />
                </HStack>
            </>
        )}
    </Editable.Root>
</Wrapper>

### Start in Edit View

Use `defaultEditing` to start in edit mode.

<Wrapper>
    <StartWithEditViewEditable />
</Wrapper>

### Submit Mode

Use `submitMode` (`"both"`, `"enter"`, `"blur"`, or `"none"`) to control when edits commit.

<Wrapper>
    <Editable.Root defaultValue="Meow" placeholder="Enter an animal sound" submitMode="enter">
        <Editable.Preview />
        <Editable.Input />
        <HStack>
            <Editable.EditButton />
            <Editable.SubmitButton />
            <Editable.CancelButton />
        </HStack>
    </Editable.Root>
</Wrapper>

### Final Focus Ref

Use `finalFocusRef` to direct focus when edit mode closes.

<Wrapper>
    <FinalFocusRefEditable />
</Wrapper>
