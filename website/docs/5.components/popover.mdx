## Installation

```bash
pnpm dreamy add popover
```

## Usage

Popover behavior (focus, dismiss, positioning) is provided by [Ark UI Popover](https://ark-ui.com/docs/components/popover). Dreamy owns styling, compound parts, and Motion enter/exit on the content surface. Use `open`, `defaultOpen`, and `onOpenChange` for controlled state.

Floating content uses Ark `Positioner` + `Content` inside Dreamy [`Portal`](/docs/components/portal) (not Ark’s portal) so z-index stacking, nested overlays, and `portalProps.containerRef` keep working. Set `hasArrow` on the root; the pointer is `Popover.Arrow` + `Popover.ArrowTip` from Ark, styled via the popover recipe.

When Popover opens, focus moves into the panel (when `autoFocus` is enabled). When it closes, focus returns to the trigger. Set `hasArrow` on `Popover.Root` to render the pointer (optional `arrowSize` / `arrowShadowColor`).

Use `reduceMotion` on the root or rely on `DreamyProvider` to skip scale/fade transitions. Optional `isLazy` defers mounting until the first open. The panel stays in the DOM during close so the scale/fade exit animation can complete.

### Automatic overlay stacking

Popover content renders through the shared [Portal](/docs/components/portal) stack at the `popover` layer (1500). Inside another Dreamy UI overlay, its portal becomes a nested scope and adds that layer to its parent base automatically. No `usePortal={false}`, manual layer, or z-index workaround is needed.

Active popovers at the same layer follow open order. A later sibling Modal still covers an earlier Modal's complete subtree, including open popovers.

Popover-based composites expose the same escape hatch through `popoverProps.portalProps`. Use `portalProps.containerRef` only to target the non-scrolling overlay root of a native or third-party overlay.

```tsx
const overlayRef = useRef<HTMLDivElement>(null);

// Attach overlayRef to the third-party overlay's non-scrolling root.
<Popover.Root portalProps={{ containerRef: overlayRef }}>
    <Popover.Trigger>
        <Button>Open Popover</Button>
    </Popover.Trigger>
    <Popover.Content>Rendered in the external overlay root</Popover.Content>
</Popover.Root>
```

### Controlled Popover

Most of the time, you'll want to control the popover's open state with `useState` and `open` / `onOpenChange`.

<Wrapper>
	<ControlledPopover />
</Wrapper>

```tsx
export function ControlledPopover() {
    const [open, setOpen] = useState(false);

    const handleDelete = useCallback(() => {
        /**
         * Handle delete logic...
         */
        setOpen(false);
    }, []);

    return (
        <Popover.Root
            hasArrow
            open={open}
            onOpenChange={({ open: nextOpen }) => setOpen(nextOpen)}
        >
            <Popover.Trigger>
                <Button variant={"primary"}>Open Popover</Button>
            </Popover.Trigger>

            <Popover.Content>
                <Popover.CloseButton />
                <Popover.Header>Delete Post</Popover.Header>
                <Popover.Body>
                    Are you sure you want to delete this post? This action cannot be undone.
                </Popover.Body>
                <Popover.Footer>
                    <Button variant={"solid"} onClick={() => setOpen(false)}>
                        Cancel
                    </Button>
                    <Button variant={"primary"} onClick={handleDelete}>
                        Delete
                    </Button>
                </Popover.Footer>
            </Popover.Content>
        </Popover.Root>
    );
}
```

### Initial Focus

You can set the initial focus element using `initialFocusRef` prop.

<Wrapper>
	<FocusPopover />
</Wrapper>

```tsx
export function FocusPopover() {
    const [open, setOpen] = useState(false);
    const initialFocusRef = useRef<HTMLButtonElement>(null);

    return (
        <Popover.Root
            hasArrow
            open={open}
            onOpenChange={({ open: nextOpen }) => setOpen(nextOpen)}
            initialFocusRef={initialFocusRef}
        >
            <Popover.Trigger>
                <Button variant={"primary"}>Open Popover</Button>
            </Popover.Trigger>

            <Popover.Content>
                <Popover.CloseButton />
                <Popover.Header>Delete Post</Popover.Header>
                <Popover.Body>
                    Are you sure you want to delete this post? This action cannot be undone.
                </Popover.Body>
                <Popover.Footer>
                    <Button variant={"solid"} onClick={() => setOpen(false)} ref={initialFocusRef}>
                        Cancel
                    </Button>
                    <Button variant={"primary"}>Delete</Button>
                </Popover.Footer>
            </Popover.Content>
        </Popover.Root>
    );
}
```

### Placement

You can customize the placement of the popover relative to the trigger element using the `positioning` prop.

<Wrapper>
	<PlacementPopovers />
</Wrapper>

```tsx
const placements = [
    "top", "bottom", "left", "right",
    "top-start", "top-end", "bottom-start", "bottom-end",
    "left-start", "left-end", "right-start", "right-end"
];

export function PlacementPopovers() {
    return (
        <Flex wrapped gap={5}>
            {placements.map((placement) => (
                <PlacementPopover key={placement} placement={placement} />
            ))}
        </Flex>
    );
}

export function PlacementPopover({ placement }: { placement: string }) {
    return (
        <Popover.Root hasArrow positioning={{ placement }}>
            <Popover.Trigger>
                <Button variant={"primary"}>{placement}</Button>
            </Popover.Trigger>

            <Popover.Content>
                <Popover.CloseButton />
                <Popover.Header>Delete Post</Popover.Header>
                <Popover.Body>
                    Are you sure you want to delete this post? This action cannot be undone.
                </Popover.Body>
                <Popover.Footer>
                    <Button variant={"primary"}>Delete</Button>
                </Popover.Footer>
            </Popover.Content>
        </Popover.Root>
    );
}
```

### Size

Use `size` prop to set the size of the popover.

<Wrapper>
	<SizePopovers />
</Wrapper>

```tsx
export function SizePopovers() {
    return (
        <Flex
            wrapped
            gap={5}
        >
            {(
                ["sm", "md", "lg", "xl", "2xl", "3xl", "4xl", "5xl", "6xl", "7xl", "8xl"]
            ).map((size) => (
                <SizePopover key={size} size={size} />
            ))}
        </Flex>
    );
}

export function SizePopover({ size }: { size: string }) {
    return (
        <Popover.Root hasArrow size={size as any}>
            <Popover.Trigger>
                <Button
                    variant={"primary"}
                    w="fit-content"
                >
                    {size}
                </Button>
            </Popover.Trigger>

            <Popover.Content>
                <Popover.CloseButton />
                <Popover.Header>Delete Post</Popover.Header>
                <Popover.Body>
                    Are you sure you want to delete this post? This action cannot be undone.
                </Popover.Body>
                <Popover.Footer>
                    <Button variant={"primary"}>Delete</Button>
                </Popover.Footer>
            </Popover.Content>
        </Popover.Root>
    );
}
```
