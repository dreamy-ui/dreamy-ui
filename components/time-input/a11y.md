# Time Input — Accessibility Requirements

Segmented time control with configurable hour / minute / second / millisecond fields, optional AM/PM, and a scroll-wheel popover.

**APG:** Closest patterns are [Spinbutton](https://www.w3.org/WAI/ARIA/apg/patterns/spinbutton/) for segments and [Dialog (Modal)](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) practices for the popover panel (non-modal).

---

## Dreamy form composition

Compose inside **`Field`**. Field owns the overall label/hint/error for the time value.

```tsx
<Field.Root>
  <Field.Label>Start time</Field.Label>
  <TimeInput.AIO hour12 name="startTime" />
  <Field.Error>Enter a valid time</Field.Error>
</Field.Root>
```

---

## Anatomy

| Part | Component | A11y role |
| --- | --- | --- |
| **Root** | `TimeInput.Root` | Group + popover owner |
| **Trigger** | `TimeInput.Trigger` | `role="group"`, `aria-expanded`, `aria-haspopup="dialog"` |
| **Segment** | hour / minute / second / millisecond / period | `role="spinbutton"` with valuemin/max/now/text |
| **Content** | `TimeInput.Content` | `role="dialog"`, `aria-label="Choose time"` |
| **Columns** | scroll wheels | Pointer / scroll selection; not required in tab order |

### Connections

```
Field.Label ──► Trigger (aria-labelledby via Field)
Field.Hint+Error ──► aria-describedby on Trigger
Hidden input ──► form name/value (format follows `fields`)
Segments ──► Left/Right move; Up/Down change; digits type
Open ──► focus first segment by default
```

---

## Requirements

### Roles & naming

- Trigger exposes expanded/collapsed state for the popover.
- Each segment is a spinbutton with a clear accessible name (Hour, Minute, Second, Millisecond, AM/PM).
- Hidden native value follows the active `fields` (for example `HH:mm`, `HH:mm:ss`, `ss.SSS`).

### Keyboard

| Key | Behavior |
| --- | --- |
| **Click / Enter / Space** | Open or close the popover; opening focuses the first segment |
| **ArrowLeft / ArrowRight** | Move between active segments |
| **ArrowUp / ArrowDown** | Increment / decrement the focused segment (wraps) |
| **0-9** | Type into the focused numeric segment (native-like buffering) |
| **A / P** | Set AM / PM when the period segment is focused |
| **Escape** | Close the popover |

### Pointer

- Clicking the trigger opens the popover (not only the clock icon).
- Wheel columns support click-to-select, drag scroll, and mouse wheel.
- Numeric columns loop infinitely.
